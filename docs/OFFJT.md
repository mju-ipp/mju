# docs/OFFJT.md — OFF-JT 기간(3~7월) 앱 사용: 할 일 알림 중심 (2026-10-16 초안)

> 배경: 사용자 10/16 — OFF-JT에서도 앱을 써야 함. OFF-JT 출결은 **교수 수기출석부**(공식 기록, 앱이 대신하지 않음)라 학생이 앱으로 할 출결 행동이 없다. 앱의 역할은 **학생에게 할 일을 제때 알리는 것**(학습활동서·출석결과확인·행사).
> 알림 종류는 사용자 미지정 → 시간표 없이 되는 것부터. 시간표는 센터가 이미 만드는 **직무별 수업일정 엑셀을 그대로 올리는 방식**(사용자가 10/16 파일 위치 공유).
> 시기: 2027 기수 OFF-JT가 3월 시작 → **2월 말까지** 배포. MULTI_TEACHER.md 다음 순서. 단, 1단계는 작아서 언제든.

## 현황 (실측 10/16)
- 비콘 알림 `send_beacon_reminders`(평일 09:00·16:00 크론): 대상 = 이번 달 `attendance_monthly` 실적 < 배정인 학생 **전부**. OFF-JT 구분 없음 → 3월이 되면 OFF-JT 학생에게 "입실 비콘" 알림이 매일 감.
- 일정(`calendar_events`): mju 0건. `job_key`(직무) 칸이 있어 직무별 일정 자리는 있음.
- 이번 달 마감(tasks)·학생 완료 체크(sql/41)·독촉 공지(D-3부터 관리자가 수동)가 있음.
- 자동 공지 발송 틀: `auto:beacon-*` 공지 + `notice_recipients` 개인 본문 + push-sender — 같은 틀로 새 알림을 만들 수 있음.

## 단계

### 1단계 — 학생 단계(OFF-JT/OJT) 구분 + 비콘 알림 OJT만
- 학생 단계 = 기수·월로 계산(3~7월 OFF-JT, 8~익년 2월 OJT), 학생별로 바꿀 수 있게 `students.phase_override`.
- `send_beacon_reminders`가 OJT 학생에게만 보내게.
- **확인:** 날짜를 3월로 놓고 함수를 시험 DB(pglite)에서 돌려 OFF-JT 학생 0명.

> **10/16 사용자 결정으로 아래 2~4단계 재정리:** 학습활동서는 **한 달 단위로 체크**, 알림은 **월초에 "지난달 학습일지 + 출석결과확인 하세요"** 식. 수업일 저녁 알림·날짜별 [작성함]·금요일 점검은 하지 않는다. 직무별 수업 달력은 참고용(선택)으로만.
>
> **새 2단계 — 월 학습활동서 할 일 자동 생성 + 월초 알림 (OFF-JT·OJT 공통)**
> - 매월 1일 0시: "M월분 학습활동서 작성 + 출석결과확인 등록(고용24)" 할 일을 자동으로 만든다(대상 = 진행중 학생, OFF-JT·OJT 모두). 메모도 그 달 숫자로 자동 — 지금은 손으로 고쳐 쓰다 보니 10월분 할 일 메모에 "8월 학습일지"가 남아 있음(10/16 확인).
> - 알림: 1일 09:00 전원 "지난달(M월) 학습활동서 마무리하고 [출석결과확인 등록]까지 눌러주세요" → 마감 D-1 09:00 앱에서 완료 체크 안 한 학생만 한 번 더.
> - 학생 앱: 홈의 이번 달 할 일 카드에서 [완료] 체크(지금 기능 그대로, sql/41 task_checks).
> - 관리자: 오늘 › 이번 달 마감의 '완료 n/17'·미완료 이름은 그대로, 자동 발송 기록 표시. 수동 독촉 버튼 유지.
> - OFF-JT 문구에는 "수업한 날마다 과목별로", OJT 문구에는 "훈련한 날마다"를 넣는다(단계는 sql/59 판정).
>
> **새 3단계(선택) — 직무별 수업 달력:** 수업일정 엑셀을 올려 학생 달력에 날짜별 과목·능력단위를 참고로 표시. 알림·체크 없음.
>
> 아래 옛 2~5단계는 기록용.

### (옛) 2단계 — 마감 자동 독촉 (OFF-JT·OJT 공통)
- 이번 달 마감 할 일마다 자동 발송 시점: 말일 · 1일("[출석결과확인 등록] 버튼이 열렸어요") · D-3 · D-1. **완료 체크 안 한 학생만.**
- 관리자: 할 일마다 [자동 독촉 켜기], 발송 예정·기록 표시. 지금의 수동 독촉 버튼은 그대로 둠.

### 3단계 — 금요일 주간 점검 (OFF-JT)
- 금요일 16:00 OFF-JT 학생에게 "이번 주 학습활동서 빠진 날 없는지 확인해요". 시간표가 있으면 "이번 주 수업 3일"까지 넣음.
- 관리자에서 켜기/끄기·문구 수정.

### 4단계 — 직무별 수업일정 엑셀 → 학생 일정 + 수업일 알림
- **지금 센터가 학생에게 주는 자료(10/16 확인):** 직무 폴더(`Z:\…\2026년 학습활동서작성\<직무>\`)마다 ① **수업일정 엑셀** — 월별 시트(3~7월), 달력 격자, 날짜 칸 아래에 `과목 / 능력단위` 쌍이 줄로 쌓임(예: 3/2 월 = 모바일프로그래밍·애플리케이션 테스트 관리 + 캡스톤디자인1·통합구현). `★` = 그날부터 새 능력단위, 색칠 칸 = 직업기초능력. ② **학습안내서 PDF/PPTX** — 과목→능력단위(코드·시간·교사)→능력단위요소→학습활동(수행과업).
- **형식이 전 직무 같음:** 2026년 엑셀 30개 모두 같은 격자(날짜 행 5개, 요일 머리). 기업별 변형 파일 있음(예: `_덱스,에스테이트`, `_멜콘 3월`, `_인지컨트롤스`, `_씨티케이`) → 직무 + (선택) 기업으로 매칭.
- **입력(선생님, 학기 초·변경 때):** 지금 만드는 수업일정 엑셀을 **그대로 끌어놓기** → 직무(·기업) 고르기 → 날짜별 과목·능력단위 미리보기 → 올리기. 월별 수정본(`_4월.xlsx`)을 다시 올리면 그 달만 교체.
- **학생 앱:**
  - 일정 달력에 '내 수업'(날짜별 과목·능력단위), `★` 날은 "새 능력단위 시작" 표시.
  - 홈 카드 "오늘 학습활동서 2개 — 모바일프로그래밍(애플리케이션 테스트 관리) · 캡스톤디자인1(통합구현)" + [작성함] 체크.
  - 월말 "이번 달 학습활동서 쓸 날 14일 · 체크 9일" 목록.
- **알림:** 수업 있는 날 18:00 "오늘 수업 학습활동서 써주세요 — 모바일프로그래밍(애플리케이션 테스트 관리) 외 1과목". [작성함] 체크한 날은 금요일 점검에서 빠짐.
- **학습안내서:** 1차는 직무별 PDF를 자료로 연결(학생 직무에만 보이게). 2차(선택)로 PPTX 표를 읽어 능력단위를 누르면 능력단위요소·수행과업이 펼쳐지게 → 학습활동서 쓸 때 참고 문장.

### 5단계 — 행사 전날 알림
- 일정에 직업기초능력·직무교육·특강·기업방문데이를 넣으면 전날 오후 해당 학생(전체/직무)에게 알림.
