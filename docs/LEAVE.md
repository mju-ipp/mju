# 휴가·출장 체크 → 정규시간 옮기기 (2026-10-22~, 계획)

사용자 결정(10/22): 선생님이 그 달 OJT 정규시간을 먼저 쭉 등록해 두고(행정지원시스템 + 앱 날짜별 예정), **휴가·출장 가는 날만 체크**하면 그날을 다른 날로 옮긴다. 체크는 **학생·현장교사 둘 다** 할 수 있고, 누가 체크했는지 남긴다. 목적: 기록 없는 날이 생긴 뒤에 옮기는 대신, 그날이 오기 전에 옮긴다. 다음 단계로 현장교사에게 날짜별 능력단위를 알려 학습 품질을 높이는 데 쓴다.

## 현황
- 날짜별 예정 = `attendance_daily`(status planned, 시작·끝·시간·course). 10월은 출석결과 엑셀 올리기로, 11월은 10/22 시간표 기준으로 직접 넣음(129행).
- 옮기기 = 출결점검 스킬 `scripts/move.py`(행정지원시스템 [일 훈련시간 조회]에서 삭제·입력·저장). 규칙: 교집합 기준, 가장 빠른 빈 평일, 하루 6h(09-12+13-16, 프라임 10-17), 과정 합계 유지.
- 학생 본인 확인 = 코드·서명토큰(`my_attendance` 방식). **현장교사 접속 길은 없음** — `company_contacts.role` 은 'hrd' 만(현장교사 확장 대비 칸만 있음).

## 단계
1. **DB — sql/69_absence.sql**
   - `attendance_absences`(center_id, company, course, name, day, kind 휴가|출장, by_role student|teacher|admin, by_name, note, state 접수|반영|취소|반려, created_at, handled_at). 같은 학생·날짜 하나(취소 뒤 다시 가능).
   - `company_links`(center_id, company, token_hash, label, expires_at, revoked_at) — 현장교사용 기업 링크. 원문 토큰은 만들 때 한 번만 보여 줌.
   - 학생 RPC: `my_absences(code, token, month)`, `report_absence(code, token, day, kind, note)`, `cancel_absence(…, id)` — 명단 students 기준, 본인 것만.
   - 현장교사 RPC: `company_plan(link, month)`(그 기업 학생들의 날짜별 예정 + 체크) · `company_report_absence(link, name, day, kind, note)` · 취소. 링크 확인 실패는 IP 제한.
   - 공통 제한: 그 학생에게 **정규시간(예정 포함)이 있는 날**만. 마감 없음.
   - 관리자: `admin_absences(month)`, `admin_set_absence_state`, `admin_make_company_link`/`revoke`.
   - rls-check MUST_BE_BLOCKED·DELETE_BLOCKED 에 두 표 등록, pglite 시험.
   - 10/22 작성: 본인 확인은 sql/65 `_chat_me` 재사용, 링크는 64자 무작위·sha256 저장·끊기/기한, 틀린 링크는 IP 10분 30회(`linkfail:`). 학생 체크 10분 30건, 링크당 10분 60건. 반영(applied)된 체크는 학생·현장교사가 못 바꿈. pglite 41 PASS(scratchpad pgl/test69.mjs — 다른 기업·다른 센터 0건, anon 직접·내부 함수 차단, 끊은·지난 링크 거절). **운영 적용 전**.
2. **학생 화면** — 일정 달력의 내 정규시간 날을 누르면 [휴가][출장] 체크·취소. 같은 과정에 학생이 여럿이면 "이 날은 과정 전체가 옮겨집니다" 안내.
   - 10/22 작성(index.html 홈 달력, student.css `.ab-*`, sw v56): 펼친 날 칸에 체크 묶음(메모 선택 → [휴가][출장], 확인 창), 체크한 날은 달력 칸에 '휴가'/'출장', 접수 중이면 [체크 취소], 옮긴 날은 '다른 날로 옮겼어요', 현장교사가 체크했으면 이름 표시. 인정된 날에는 안 보임(예정·기록 없음·모자람만). 달마다 my_absences 한 번(체크·취소 후 그 달만 다시). RPC 실패면 체크 칸 없이 기존 화면. 모의 서버(scratchpad px/mockserver.mjs)로 체크·취소·옮긴 날·375px 확인.
3. **현장교사 화면 `field.html?k=<링크>`** — 로그인 없음. 그 기업 학생 × 날짜 표(이번 달·다음 달), 칸을 눌러 휴가/출장 체크. 날짜별 능력단위는 다음 작업에서 이 화면에 붙임.
4. **관리자 '오늘 › 휴가·출장 N건'** — 접수 목록 + **옮길 날 자동 제안**(과정 단위: 한 명이라도 빠지는 날은 그날 전체, 그 달 안의 빈 평일 → 모자라면 경고). [이동 계획 받기] = `move.py` 형식 json. 반영 뒤 재조회·올리기 하면 그 날 접수는 '반영'으로 바뀜(예정이 사라진 날 = 반영). 기업 링크 만들기·끊기도 여기.
5. **알림** — 새 접수가 오면 담당 선생님 콘솔 배지. 학생·현장교사에게 "옮겨졌습니다" 알림은 반영 때(푸시, 시험 발송은 사용자 허락 후).

## 정한 것 (10/22)
- ① 체크는 **언제든**(마감 없음). 예정이 있는 날이면 지난 날도 받는다 — 지난 날은 옮기기 규칙상 그대로 옮길 대상.
- ② **출장도 옮긴다**(휴가와 같게 처리, 종류만 기록).
- ③ 현장교사는 **기업 링크로, 그 기업 학생만**. 링크는 선생님이 기업에 전한다.
- ④ 그 달 안에서 옮길 날을 못 찾는 일은 거의 없을 것 — 경고만 띄우고 선생님이 판단.

## 검증 기준
- 다른 기업·다른 센터 접수 0건(학생·링크 모두), anon 직접 접근 차단, 끊은 링크·지난 날짜·예정 없는 날 거절.
- 제안한 이동 계획을 적용하면 과정 월 합계가 그대로이고 체크한 날의 정규시간이 0.
