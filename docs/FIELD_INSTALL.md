## 사용자 결정 (10/27)
1. 안내 = **행사·기업 방문 때 현장에서 학생 폰에 직접 설치·알림 켜기까지.**
2. **초대코드가 들어간 개인 링크** 만들기(학생이 코드를 칠 필요 없게).
3. 다른 선생님 학생의 대화방 글은 **당분간 권순천이 답함**(콘솔 계정은 나중에). 글 이름은 방 담당 선생님으로 나감(sql/80 결정 그대로).
4. 안 한 학생 점검은 **따로 표 없이** — 학생 › 명단의 가입·알림·마지막 앱 사용 열로.

## 만들 것
1. **개인 링크 `index.html?code=XXXX`** — 가입 화면에서 대상 '학생'을 미리 고르고 초대코드 칸을 채움. 학생은 필수 동의 2개 체크 → [가입]만. 읽은 뒤 주소에서 코드를 지움(history.replaceState — 화면 캡처·공유로 코드가 퍼지지 않게). 설치앱(안드로이드)의 '내 정보 불러오기' 칸도 같은 값으로 채움.
   - 아이폰은 홈 화면 앱이 사파리와 저장소가 따로라 링크의 코드가 넘어가지 않음 → 홈 화면 앱을 처음 열면 '내 정보 불러오기'에 코드를 한 번 입력해야 함(카드에 큰 글씨로 인쇄해서 해결).
2. **설치 카드 인쇄 (관리자 › 학생 › 명단)** — 담당·기업으로 거른 뒤 학생을 고르고 [설치 카드 인쇄] → 새 창에 A4 인쇄용(한 장 8명, 기업별 묶음): 이름·기업·**QR(개인 링크)**·**초대코드 큰 글씨**·기기별 순서.
   - 안드로이드: QR → 가입(동의 체크) → [알림 켜기] → 홈 화면에 추가
   - 아이폰: QR → 사파리 공유 › 홈 화면에 추가 → 홈 아이콘으로 열기 → 코드 입력 → [알림 켜기]
   - QR 은 브라우저 안에서 만듦(cdnjs `qrcode-generator`) — 이름·코드가 외부 서버로 나가지 않음. 파일로 저장하지 않고 인쇄만.
3. **현장 확인** — 설치 직후 명단 새로고침으로 그 학생 '가입·알림' 표시 확인(새 화면 없음).

## 하지 않는 것
- 문자·카톡 일괄 발송, 선생님별 현황표, 다른 선생님 콘솔 계정(나중에).

## 확인 기준
- 모의: `?code=` 로 열면 학생·코드가 채워지고 주소에서 코드가 사라짐, 가입 완료까지 오류 0. 설치 카드 인쇄 미리보기에서 QR 을 읽으면 그 학생 개인 링크.
- 운영: 첫 방문 뒤 그 기업 학생들 '가입·알림' 이 명단에 잡히는지.

## 진행 (10/27)
