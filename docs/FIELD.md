# 현장교사 페이지 — 설계안 (2026-10-22, 계획)

사용자 요청(10/22): 현장교사 페이지를 따로 설계. 휴가·출장 체크(docs/LEAVE.md 3단계 field.html)에 더해 **학생 비콘(입퇴실) 시간 확인, 능력단위, 내부평가, 외부평가**를 보고 **내려받을 수 있게**.

## 누가·어떻게 들어오나 (지금과 같음)
- 기업마다 링크 하나(`field.html#k=<64자>`, sql/69 company_links). 로그인 없음, 그 기업 학생만. 끊기·기한은 관리자 콘솔에서.
- 현장교사는 기업 HRD 담당이 아니라 OJT 를 가르치는 사람 — "이번 달 뭘 가르치고, 학생이 제대로 출석했고, 언제 무엇을 평가하나"가 한 화면에 있어야 함.

## 화면 구성 (탭 4개, 휴대폰 우선)
1. **이번 달** (첫 화면) — 결론 한 줄("11월 OJT 40시간 · 남은 훈련일 5일 · 내부평가 1건")
   - 날짜별 훈련: 정규시간 · 학생별 인정 시간 · 상태(인정/모자람/기록 없음/예정) — 모자란 날은 위 경고 상자로.
   - 날마다 [휴가][출장] 체크(지금 기능 그대로).
2. **능력단위** — 월별 OJT 능력단위(시간표 월 배정 시간), 단위마다 학습안내서 요소·수행과업, ★이번 달. 내부평가 시기 표시.
3. **내부평가** — 달마다 평가 대상 단위, 평가지(학생별)·정답지 내려받기, 센터 접수 여부.
4. **자료** — 센터가 그 기업에 올린 파일 목록(시간표, 학습안내서, 평가지, 안내문) 내려받기.

## 쓸 자료 (있는 것 / 새로 필요한 것)
| 내용 | 원천 | 상태 |
|---|---|---|
| 정규시간·비콘 입퇴실·인정 | attendance_daily(in_time, out_time, method, recognized) — 매일 조회 후 올린 값 | 있음(조회일 기준, 실시간 아님) |
| 월 OJT 시간·능력단위 | attendance_monthly(planned_hours, units) | 있음 |
| 단위 요소·수행과업 | offjt_units(subject 'OJT') 학습안내서 | 일부 과정만 입력됨 |
| 내부평가 시기 | 실시신고 OJT 시간표 '내부평가시기' 열 | **앱에 없음** → 표로 올려야 함 |
| 내부평가지·정답지 파일 | 11_자동화도구\내부평가지 출력(hwp/pdf) | **앱에 없음** → 비공개 저장소에 올림 |
| 외부평가 일정·종목·필수단위 | 공단 공지 / 큐넷·HRDK 자료 | **앱에 없음** → 직무별로 입력 |

## 기술 설계 요점
- 파일은 **비공개 버킷 + 서명 URL**(CLAUDE.md 규칙 8). 현장교사는 로그인이 없으니 엣지 함수 `field-file`이 링크 토큰을 확인 → 그 기업 파일만 5분짜리 서명 URL 발급. 경로 = `<center>/<company_key>/<종류>/<파일>`.
- 새 표(안): `field_files`(center_id, company_key, kind 시간표|학습안내서|내부평가|외부평가|안내, month, title, path, for_name(학생별 평가지면 학생), uploaded_by), `eval_schedule`(center_id, course, unit, kind 내부|외부, month 또는 날짜, 장소, 메모, done_at).
- 현장교사 RPC 는 지금처럼 `_link_me` 로 확인: `field_home(link, month)`(이번 달 + 비콘), `field_units(link)`, `field_evals(link)`, 파일은 엣지 함수.
- 관리자 콘솔: 학생 › 기업 단위로 "현장교사 자료" 올리기(여러 파일, 종류·달·학생 지정), 평가 일정 입력, 링크 관리(지금 '오늘'에 있는 것을 여기로 옮김).
- 내부평가지 생성 도구(build.py)가 만든 `_기업발송` 폴더를 통째로 올리는 길 — 파일 이름에서 학생·달을 읽음.

## 단계 (안)
1. 시안 — 4개 탭 화면을 정적 HTML 로(모의 자료), 사용자 확인.
2. 이번 달 탭 = 지금 field.html 확장(비콘 시간·인정·상태) — 새 표 없이 sql 함수 하나.
3. 능력단위 탭 — 있는 자료로.
4. 파일: 버킷·field_files·엣지 함수·관리자 올리기.
5. 평가 탭: eval_schedule·내부평가 파일 연결·외부평가 입력.

## 시안 v2 (10/22 사용자 피드백 "출장 표시가 보기 어렵다", "HRD담당자도 — 월별 출결확인, 전담인력수당신청")
- **휴가·출장**: 날짜마다 학생별 버튼을 없애고, 위에 '휴가·출장' 묶음(알린 것 목록 + 취소/옮긴 날) + **[휴가·출장 알리기] 버튼 하나** → 시트에서 학생(여러 명)·훈련일(여러 날)·휴가/출장·메모. 날짜 목록은 상태만, 휴가·출장 줄은 코발트 띠.
- **역할**: 기업 링크마다 역할(현장교사 / HRD담당자, company_links.role 추가 예정). 현장교사 탭 = 이번 달·능력단위·내부평가·자료, HRD담당자 탭 = **월별 출결 · 전담인력수당 · 휴가·출장 · 자료**.
- **월별 출결(HRD)**: 달마다 마감 단계(정규시간 등록 → 출결 → 학습활동서 → 학생 출석확인 → 센터 확인)와 막힌 단계, 학생별 인정/계획·학습활동서 n/n일·출석확인 날짜.
- **전담인력수당(HRD)**: 기간별 상태(출결 진행 중 / 미신청 / 신청 → 승인 → 확정 → 지급완료)·신청일, 미신청이면 경고. 원천 = 센터가 행정지원시스템 비용관리(전담자)에서 확인한 값(자동 조회 또는 손 입력) — 금액은 안 보임(미정).
- 새로 필요한 자료: 학생별 학습활동서 작성일 수·출석확인 날짜(출석결과 엑셀에 있음 → app_export 에 넣어 올림), 월차 센터 확인 상태, 전담인력수당 상태 표.

## 정한 것 (10/22)
- ① 비콘은 **인정 시간·상태만**(입실·퇴실 시각은 안 보임) — '이번 달' RPC 도 시각을 돌려주지 않는다.
- ② 내부평가 **정답지도 준다**(평가자 = 현장교사). 학생 화면에는 어느 쪽도 안 보임.
- ③ **외부평가 탭은 뺀다** → 탭 = 이번 달 · 능력단위 · 내부평가 · 자료. (위 표의 외부평가 줄·eval_schedule 의 외부 종류는 쓰지 않음)
- ④ **시안부터** — `04_일학습병행앱_v2\design\현장교사_시안.html`(모의 자료, 10/22). 확인 뒤 2단계부터.
